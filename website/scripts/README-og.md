`public/og.png` is the social card (1200x630).

It was generated by a temporary Next `app/opengraph-image.tsx` using
`next/og`'s ImageResponse, then copied here as a real `.png`. The route
convention serves the file extensionless (`/opengraph-image`), and a static
host returns it with no Content-Type, which Twitter and Facebook reject. A
file in `public/` keeps its extension and is typed correctly everywhere.

To change the card, re-create that route file, `npm run build`, copy
`out/opengraph-image` to `public/og.png`, and delete the route again.
